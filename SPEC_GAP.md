# Spec-diff coverage gap

Generated by diffing the registered stdlib against Microsoft's public
Power Query M function reference (learn.microsoft.com/en-us/powerquery-m/*-functions),
namespace by namespace. This finds standard functions the 500-workbook corpus never
exercised, so corpus coverage (files fully evaluated) missed them.

- Reference functions collected: ~509 (excluding internal-only / query-folding entries)
- Registered: 491
- **Missing standard functions: 144**

The clean-room rule is unchanged: names/signatures/semantics come from the public
reference only; PQTest stays a black-box CI oracle.

Correction the diff surfaced: `List.MatchesAll`, `List.MatchesAny`, and `List.Times`
are REAL M functions (they had been wrongly excluded as "user-defined" in the corpus
measurement).
